# 물류흐름 모니터링 · BM 개선 Agent

Bosch 생산라인 통과 기록으로 설비 정지·병목을 탐지하고, OR-Tools(CP-SAT)로 정비 인원 투입 순서를 정하는 Streamlit 앱입니다.

- 실행: `streamlit run app.py` (계산 결과 `results/`가 들어 있어 바로 열립니다)
- 사용 방법: `사용설명서.md` 또는 앱 사이드바의 '📖 사용 설명서'
- 원본 데이터: Kaggle 'Bosch Production Line Performance' (용량 때문에 저장소에는 넣지 않음)
